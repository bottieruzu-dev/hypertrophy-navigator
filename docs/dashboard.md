# からだのダッシュボード

起動時のホームを、体組成・筋トレ・栄養をまとめて確認できるダッシュボードに変更しました。濃紺の背景、シアン・ミント・紫のチャート、枠線付きのカードで構成しています。PCではサイドバーと複数列、スマホでは下部ナビゲーションと縦並びになります。

## 表示するもの

- 最新の実測体重、選択日のタンパク質・カロリー、期間内の筋トレ日数。
- 体重・体脂肪率・腹囲・各サイズ・睡眠・回復度と、7日平均等の計算値。項目を選択して推移を表示できます。
- 確定済みの食事から集計した栄養の目標比較と、PFCのエネルギー構成。
- 日ごとの本番セットのトレーニング量と、部位別の週間セット相当数。
- 種目別の最大重量・回数・推定1RMの推移と、Week 0の開始基準。
- 34栄養素の数値。基本・ビタミン・ミネラルを切り替えられます。
- 筋トレ・食事・体重を記録した日のカレンダー。日付を押すと基準日が変わります。
- 最近のアクティビティと、測定・Week 0・日別メニュー・有酸素運動・イベント・旧栄養ログ・送信待ちの件数。
- 栄養ページと共通の夕食提案。専用SQLと夜間タスクが未適用の場合は取得状況を表示します。

基準日と直近7/30/90日を切り替えられます。最新の実測値は基準日以前の最新値で、週間負荷は期間の選択にかかわらず基準日までの7日間です。サマリー・カレンダー・グラフは指定期間を使います。

## データと集計

ダッシュボードは既存のIndexedDBを読み取り、記録変更時に再集計します。通常の表示だけでデータを作成・更新・削除しません。「クラウド食事を更新」を押した場合のみ、既存の本人確認済みWork同期を使って選択日と前6日分の食事を取得します。クラウドの全筋トレ履歴や別端末の全データを自動復元する機能ではありません。

未入力日は栄養摂取ゼロとして平均に加算しません。不明な栄養は既知分・不明数で区別し、斜線を付けます。取消済みの食事、未来日の記録、準備セット、Week 0のセットは集計から除外します。自重種目は実施セット数に含めますが、重量は0のままです。過去日の栄養目標はその日の食事に保存した目標を優先します。

PFCの円グラフはP/C=4、F=9 kcal/gの既知分から計算し、食物繊維などにより記録済みカロリーと一致しない場合があります。全項目が不明な場合は円グラフに架空の割合を表示しません。実測体重・サイズがない場合にも仮の値は入れません。体組成の補間記録はメインの実測グラフに含めません。

既存の筋トレ・栄養・体組成・Week 0は、ホームのカード・サイドバー・下部ナビゲーションから引き続き操作できます。既存の端末データと認証・同期の仕組みは維持します。ダッシュボード単体にDB変更は不要です。

## 検証・プレビュー

`npm test`に6件の集計テストを追加しました。未記録と不明値、取消、未来日、準備セット、自重、7日負荷、過去の目標を確認します。型チェック、lint、検証ビルド、オフラインテストも実行します。

`npm run test:browser`で検証サーバーを起動し、`tests/dashboard-preview.html`を開くと架空データで表示を確認できます。データあり／未記録、期間、測定項目、栄養グループを切り替えられます。実際の個人記録や通常のアプリDBは使いません。`tests/ui.html`は隔離DBで既存の保存・移行を検証し、最後にアプリを開きます。
