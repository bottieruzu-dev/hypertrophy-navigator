# 体組成・周囲サイズの記録

体組成ページで体重、体脂肪率、ウエスト、おへそ周り、肩周り、胸周り、腕周り（上腕）、脚周り（太もも）、睡眠時間、回復度を入力できます。すべて任意。空欄は未入力で、睡眠・回復度の0は記録値として保持します。入力は当日の1記録を更新します。

ウエストとおへそ周りは別項目です。過去のウエスト値をおへそ周りへ移動・推定しません。以前にウエストとして別の位置を測っていた場合、過去の値と新しい位置の値を連続した測定として比較しないでください。腕・脚は毎回同じ側と位置を測り、脚は太もも周りとして記録します。

グラフの選択欄で全10入力項目と5計算項目を切り替え、直近30日・90日・全期間を表示できます。最新値・期間の最初との差・数値一覧を付けています。未入力は0にせず、記録日の値だけを結びます。縦軸は自動拡大で、補間値は白抜きの点です。

除脂肪体重は体重・体脂肪率から、肩／ウエスト比は両周囲から計算します。当日の保存時に、実測・既知分だけから体重7日平均、除脂肪体重30日平均、肩／ウエスト比7日平均を計算します。過去レコードの未計算項目を一括で書き換える処理はありません。

## Supabaseへの送信前

新しいおへそ周りの保存列を追加するため、[add-navel-measurement.sql](../supabase/security/add-navel-measurement.sql)をSupabase SQL Editorで全文実行してください。既存のデータ・所有者・RLS・権限は変更しません。アプリの公開更新も別途必要です。

記録の主保存先は従来どおり端末内です。クラウドへの送信は「クラウド設定」の「端末の履歴を送信」を使います。新しい送信コードは`navel_cm`を含むため、SQL適用前の送信は失敗しますが端末データは保持します。体組成のクラウドからの自動復元・端末間の競合解決は追加していません。既存の筋トレ用・栄養用バックアップには体組成を含まない点も従来どおりです。

## 検証範囲

追加した測定値の検証、旧レコード保持、移動平均、不明値と0の区別をダミーのロジックテストで検証しています。`tests/visualization.html`はtestモード専用のダミープレビューで、DB・クラウド・認証に接続しません。実Supabaseの列追加と送信、スマホの表示・入力は未検証です。
