# Hypertrophy Navigator

Week0の測定値と筋トレ履歴から、その日のジムメニューを作るReactアプリです。端末内のIndexedDBを主な保存先として、クラウド未設定・通信失敗時も記録を続けます。

## 更新内容と使い方

[日別メニューへの更新・利用手順・検証範囲](docs/training-upgrade.md)と、[新しい栄養ページの使い方](docs/nutrition-usage.md)を参照してください。

- Week0の既存測定を維持し、未測定の種目だけ省略。
- 時間、疲労、筋肉痛、直近の刺激、週間負荷から日別メニューを生成。
- セット保存、入力修正、休憩、途中再開、代替種目、完了履歴、JSONバックアップ。
- 人体画像と筋肉の位置表示、37種目の4段階フォームガイド。
- 本番ビルドでは初回読込後に画面をオフラインキャッシュ。
- 栄養ページ：体重連動の目標、食材とg／個の入力、AI用プロンプト、JSON取り込み、34栄養素の集計、修正・取り消し、栄養バックアップ。

同じ端末・ブラウザー・URLで利用すると既存のWeek0を引き継ぎます。データ消去や別URLへの移動の前には筋トレバックアップを保存してください。

## 開発と検証

既にインストール済みの依存関係を使用します。Node 24.18で検証しています。

```sh
npm run dev
npm test
npm run lint
npm run build
```

実データやクラウド設定を読み込まないローカル検証:

```sh
node node_modules/typescript/bin/tsc -b
node node_modules/typescript/bin/tsc -p tsconfig.tests.json
node scripts/test.mjs
node scripts/build-safe.mjs
node tests/offline.test.mjs
```

`build:safe`も同じ検証ビルドを型チェック付きで実行します。秘密ファイルを読まず、クラウド接続を空にした検証専用出力です。公開には通常の`build`を使い、設定はユーザー自身が管理してください。クラウドの設定値をログやGitに含めないでください。

隔離したブラウザーテスト:

```sh
npm run test:browser
```

`http://127.0.0.1:5178/tests/ui.html`を開きます。テスト専用DBとダミーデータを使い、テスト開始時にテスト専用DBのみ作り直します。通常のアプリDBは開きません。このテストは今回の作業環境にブラウザーがないため未実行です。

## 保存とクラウド

毎日22時の[夕食提案機能](docs/dinner-suggestions.md)を追加しました。確定済み栄養・プロフィール・直近の体組成と筋トレから、電子レンジで30分以内／コンビニ食品も使える夕食3案を生成し、栄養ページに表示します。献立専用SQL・アプリ公開・ローカルスケジュールの有効化が必要です。提案は摂取済みの記録には加算しません。

ChatGPT Workの栄養自動処理に向けた、架空データだけの[専用MCP接続テスト](docs/nutrition-mcp-demo.md)を追加しました。実際の食事・Supabase・確定合計にはまだ接続していません。

スマホからの計算待ち送信・WorkのOAuth付きMCP・下書きの確認確定は[栄養Work連携の適用手順](docs/nutrition-work.md)を参照してください。ローカル実装済みで、クラウドへのSQL適用・関数公開・OAuth設定・実機確認は別途必要です。

既存DB名を保持し、version 2で`plans`、version 3で新しい栄養記録、version 4でWorkの計算待ちを追加しています。クラウドは公開用接続設定だけでは動作せず、Authログイン・サーバー側の単一所有者登録・端末の所有者登録が必要です。適用手順は[Supabaseの安全な復旧](docs/supabase-security.md)を確認してください。端末保存後に筋トレを送信し、失敗した更新は送信待ちとして保持します。Week0のクラウド読込は明示操作です。筋トレ履歴の別端末への復元はJSONバックアップを使います。

筋トレバックアップ対象はWeek0・セッション・セット・日別メニューです。体組成は含みません。栄養は栄養ページの専用バックアップを使います。Work経由の依頼・下書き・確定食事にクラウド同期を追加しました。手動で追加した食事・食材辞書・栄養プロフィール設定の完全同期は対象外です。今回のWork連携について、実クラウド接続、SQL実行、画面操作、公開先の更新は未検証・未実施です。
